# Abol

## Overview

Abol is a student productivity web application designed to help university students organize their academic responsibilities and develop consistent study habits. The application combines essential academic management tools with a reward system inspired by Ethiopian coffee culture.

The name "Abol" comes from the first cup of the traditional Ethiopian coffee ceremony, symbolizing the beginning of focus, productivity, and community.

## Project Objectives

* Help students organize assignments, exams, and academic schedules.
* Encourage regular study habits through rewards and streak tracking.
* Celebrate Ethiopian coffee culture through culturally inspired design elements.
* Provide functionality even when internet access is limited.

## Planned Features

### Academic Tools

* Calendar Management
* To-Do List
* Exam Tracker
* Grade Tracker
* Focus Timer

### Motivation System

* Sini Reward System
* Daily Streak Tracking
* Unlockable Jebena Styles

### User Experience

* Light and Dark Mode
* Responsive Design
* Offline Functionality
* Local Data Persistence
